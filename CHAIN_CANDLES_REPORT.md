## Как сделки читаются из логов (сверено с GeckoTerminal)

| DEX | Строка лога | Сколько вошло в пул / вышло из пула (как у GeckoTerminal) |
|---|---|---|
| PumpSwap | `Program data:` BuyEvent `67f4521f…` / SellEvent `3e2f370a…` | Покупка: `quote_amount_in_with_lp_fee` (SOL без комиссий протокола и создателя) за `base_amount_out`. Продажа: `base_amount_in` за `user_quote_amount_out` (за вычетом всех комиссий). У варианта `buy_exact_quote_in` поля `quote_amount_in` и `user_quote_amount_in` меняются местами — берутся согласованные поля и проверяется арифметика. |
| Raydium AMM v4 | `Program log: ray_log:` (bincode, тип 3/4) | `amount_in` → `out_amount` (SwapBaseOut: `deduct_in` → `amount_out`); direction 2 — coin → pc. Адреса пула в логе нет — привязка по резервам (±50%). |
| Raydium CPMM | `Program data:` SwapEvent `40c6cde8…` | `input_amount` → `output_amount`, направление — `input_mint`. |
| Raydium CLMM | `Program data:` SwapEvent `40c6cde8…` | `amount_0` / `amount_1`, направление — `zero_for_one`. |

Тот же дискриминатор SwapEvent пишут и чужие программы (встретились в первых же минутах записи) — без стека
вызовов они читались бы как сделки.

**Правило баров GeckoTerminal:** open = close предыдущего бара, high/low включают этот open, close — последняя
сделка, объём — сумма сделок в USD; интервал без сделок бара не даёт. Проверка: 1m-бары, собранные из 300
последних сделок GeckoTerminal по пулу PAYDAY, совпали с его 1m OHLCV до 9-го знака (тест
`ChainBarSeriesTest`).

## Узлы

- **Публичный `api.mainnet-beta.solana.com`** рвёт WebSocket каждые 40–70 с (код 1006 у Ktor; отдельный
  .NET-клиент — то же; с пингом раз в 15 и 60 с и без него) — даже с одной подпиской. Для свечей не годится.
  Транзакции нового формата (версия 1) он присылает с нулевой подписью `1111…`.
- **PublicNode (`solana-rpc.publicnode.com`)** держит соединение часами, но: `getMultipleAccounts` — пачка
  меньше 20 адресов (иначе HTTP 403), соединение без подписок закрывает через минуту (1013), транзакции с
  нулевой подписью не присылает.
- **Helius** — без ключа не проверен (см. «Что дальше»).

## Ограничения прототипа

- **Цена подписки — не в сделках, а в шуме.** На бесплатном Helius прототип покрывает только ту часть списка
  наблюдения, на которую MEV-боты не шлют сотни транзакций в секунду; самые оживлённые пулы (их чаще всего и
  торгуют) отключаются как дорогие. Это свойство `logsSubscribe(mentions)`, а не кода.
- **Время сделок Raydium — оценка** по соседним событиям PumpSwap (обычно до секунды); сделка у границы бара
  может попасть в соседний бар. У PumpSwap время точное.
- **USD:** цена SOL — Jupiter (кеш 30 с), у GeckoTerminal — своя на момент сделки (расхождение обычно ≤0,1–0,2%);
  USDC принят за $1 (у GeckoTerminal ~0,999).
- **Потери сделок:** узел обрезает логи длиннее ~10 КБ («Log truncated») — событие за обрезом теряется
  (счётчик есть); транзакции нового формата v1 публичный узел присылает с нулевой подписью, PublicNode не
  присылает вовсе.
- **AMM v4:** в `ray_log` нет адреса пула — привязка по близости резервов; два AMM v4-пула одной монеты с
  близкими резервами различить нельзя (в списке наблюдения не встречалось).
- **Не поддержаны:** Meteora (DLMM/DAMM), Orca, пулы с котировкой не в SOL/USDC — пропускаются с причиной.
- **Память:** бары живут в памяти процесса (1500 баров на ТФ и пул); после перезапуска история снова берётся
  у GeckoTerminal.
- **Кредиты считаются по байтам JSON без сжатия.** Если Helius считает трафик после permessage-deflate,
  реальный расход ниже; проверить можно только сравнив счётчик с панелью Helius.

## Что дальше

1. **Прогон на ключе Helius** (пользователь вписывает `https://mainnet.helius-rpc.com/?api-key=…` в «Solana
   RPC URL», включает раздел или запускает `ChainShadowRunTest` без `CHAIN_RPC_URL` — адрес берётся из базы):
   сравнить счётчик кредитов прототипа с панелью Helius за сутки и убедиться, что соединение держится.
2. **Дорогие пулы** — другим способом: `accountSubscribe` на два хранилища пула (уведомление не чаще раза в
   слот, ~0,5 КБ, без шума MEV) даёт цену и чистый поток за слот — дёшево, но объём внутри слота схлопывается;
   либо платный тариф (`transactionSubscribe` с фильтром по аккаунтам и без неудачных транзакций, LaserStream).
3. **Подключение к стратегиям** — только по итогам сверки: для пулов с полными барами из цепочки отдавать их
   вместо GeckoTerminal (с тем же правилом закрытого бара), остальным — как сейчас.
